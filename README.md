## Selected Publications

### Positive-Unlabeled Learning with Knowledge-Structured Data

Thi Hai Yen VU, Vincent NGUYEN, Christel VRAIN, Hugo BREUILLARD, and Thi Bich Hanh DAO  
European Conference on Machine Learning and Principles and Practice of Knowledge Discovery in Databases - ECML PKDD 2026

This work studies positive-unlabeled learning in settings where data is enriched with symbolic or structured knowledge. It introduces a neuro-symbolic framework and NeuralAdjust, a method that dynamically reweights logical rules to improve learning under relational conflicts.

### Features Leverage in Graph Models for Mineral Prospectivity Mapping

Thi Hai Yen VU, Thi Bich Hanh DAO, Vincent NGUYEN, Christel VRAIN, and Hugo BREUILLARD  
Proceedings of the 40th ACM/SIGAPP Symposium on Applied Computing, 2025  
[View DOI](https://doi.org/10.1145/3672608.3707885)

This work proposes a graph construction approach for mineral prospectivity mapping that combines spatial distances with feature-based distances, improving the way geological attributes are represented in graph models.
